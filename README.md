# 🚌 Bus Booking Application

A full-stack Bus Ticket Booking Platform built using Angular and Spring Boot that enables users to search buses, book seats, and manage their travel bookings efficiently.

This project demonstrates real-world full-stack development, including REST APIs, authentication, and dynamic UI handling.

---

## 🚀 Features

- 👤 User Authentication (Login/Register)
- 🔍 Search Buses by source & destination
- 🚌 View Bus Listings with details
- 💺 Seat Selection System
- 🎟️ Book Tickets
- 📜 Booking History
- ⚡ REST API Integration
- 🔒 Secure Backend Architecture

## ⚙️ Installation & Setup

### 🔹 Clone Repository
git clone https://github.com/vatsalyasaras/Bus-Booking-App.git
cd Bus-Booking-App

---

### 🔹 Backend Setup (Spring Boot)
cd backend
mvn clean install
mvn spring-boot:run

Runs on: http://localhost:8080

---

### 🔹 Frontend Setup (Angular)
cd frontend
npm install
ng serve

Runs on: http://localhost:4200
